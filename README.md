# Savage Ender Dragon

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_523327_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/523327.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Savage Ender Dragon is a minecraft mod which adds serveral new mechanics and difficulty scaling to the Ender Dragon fight, making it a challenge and fun experience for any player
amount.

- The fight scales with the player amount
- The fight scales with world and config difficulty

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.
